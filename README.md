# Kotohibi

A quiet Japanese learning companion for Windows, browser and mobile.

Use the web app: https://kotohibi-f2fff.web.app/

Windows installers and portable builds are published under **Releases**. Download the latest Kotohibi-Setup executable to install. Existing learning progress is preserved during upgrades.

## Windows updates

Kotohibi 0.3 and later can check for a Windows release in Settings, download it directly from GitHub, verify its size and SHA-256 checksum, and open the installer. Windows may ask you to confirm because the application is unsigned. The installer can launch Kotohibi after installation.

The browser and home-screen app receive the current interface from the website when online. A Windows installer is needed only for native desktop changes.

## Free shared services

Accounts, progress sync and optional AI practice use a shared Firebase project and its free allowances. No paid subscription or personal AI service key is required. Usage limits can temporarily make online features unavailable. Local learning remains available.
